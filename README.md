# Cybersecurity Awareness Bot (GUI)

A WinForms chatbot that teaches you about cybersecurity.

## Features
- Voice greeting and ASCII art header
- Keyword recognition (password, phishing, scam, privacy)
- Random tips for each topic
- Memory of the user's name and favourite topic
- Sentiment detection (worried, curious, frustrated)
- Follow ups like "tell me more"

## How to run 
1. Install the .NET SDK
2. Run `dotnet run` in the project folder
